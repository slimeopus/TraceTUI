# 🛠️ Глобальный контекст проекта

## 🤖 Инструкция по поведению ИИ (Strict Rules):
- **Запрет на неопределенность:** Тебе строго запрещено писать "хз", "я не знаю" или обрывать ответ. Если тебе не хватает данных, ты обязан написать: *"Мне не хватает контекста. Пожалуйста, покажи файл [Имя] или структуру папки [Путь]"*.
- **Язык общения:** Отвечай исключительно на русском языке, развернуто и по делу.
- **Комментарии:** Всегда снабжай сложную логику, регулярные выражения и ключевые функции краткими комментариями.

## 📊 Динамическое определение стека:
- Ты должен **самостоятельно определить** язык программирования (JavaScript, TypeScript, Python или любой другой), фреймворки и базу данных, просканировав файлы в корне проекта (например: `package.json`, `requirements.txt`, `pyproject.toml`, расширения файлов `.ts`, `.py`, `.js`).
- Всегда подстраивай свой синтаксис, линтеры и стандарты форматирования под автоматически обнаруженный стек проекта.

## 📐 Архитектурные требования:
- **Баланс и простота:** Код должен быть максимально простым, понятным и читаемым. Избегай овернижиниринга (лишнего усложнения), если задача тривиальна.
- **Чистая архитектура:** При проектировании крупных фич и модулей разделяй логику на слои (данные, бизнес-логика, транспорт/API). Придерживайся принципов SOLID и DRY.
- **Инициатива:** Если пользователь дает тебе только верхнеуровневый дизайн или описание фичи, ты должен самостоятельно спроектировать оптимальную и чистую архитектурную структуру для реализации.

## 🛠️ Окружение:
- Проект ведется с использованием Git. Пиши код так, чтобы его изменения было легко отслеживать, изолируй фичи в логические блоки или функции.
